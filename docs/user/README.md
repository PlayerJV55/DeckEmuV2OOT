# Nemyu User Handbook

This handbook is for people using Nemyu: setting it up, configuring it and fixing common problems. Developer documentation lives in [docs](../README.md).

A copy of this handbook is [available online](https://gitlab.com/nemyu-emulator/nemyu/-/blob/nemyu/docs/user/README.md).

Bug reports, feature requests and questions go to the [issue tracker](https://gitlab.com/nemyu-emulator/nemyu/-/issues); use the Bug template only for actual bugs. When reporting a problem, attach your log file (see [How To Access Logs](./HowToAccessLogs.md)).
